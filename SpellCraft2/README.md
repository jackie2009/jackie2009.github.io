# 沃玛森林 · 法师战斗演示（three.js）

一个单文件的 3D 战斗 + 3C 演示：法师手持「骨玉权杖」，在沃玛森林用火球术清剿半兽人。

## 运行
- **最简单**：直接双击 `index.html`（Chrome / Edge / Safari），需要联网从 CDN 加载 three.js。
- 或双击 `start.command` 用本地服务器打开（首次可能需要在“系统设置 → 隐私与安全性”里允许运行）。
- 离线：把 three.js r170 的 `build/three.module.js` 放到 `lib/three.module.js`，再用 `start.command` 启动。

## 操作
| 按键 | 作用 |
|---|---|
| WASD | 移动（相对镜头方向） |
| Shift | 奔跑 |
| 空格 | 闪身（短距冲刺，带无敌帧） |
| 鼠标右键（按住） | 越肩瞄准（火球术）：镜头拉近、人物移到画面左侧、FOV 收窄、移动减速、人物朝向准星 |
| Q（按住） | 越肩瞄准（冰球术），与右键相同只进入瞄准 |
| 鼠标左键（按住） | 左手凝聚魔法团，0.6 秒后掷出；持续按住每 0.6 秒一发（右键=火球，Q=冰球，不瞄准时为火球） |
| V | 切换第一人称 / 第三人称（战斗逻辑完全相同） |
| R | 阵亡后复活 |
| Esc | 暂停 |

## 3C 设计要点
- **Camera**：常态镜头距离 5.2m、轻微右肩偏移（人物基本居中）；右键/Q 瞄准时距离 2.7m、肩部偏移 1.3m、FOV 62→50，全部平滑插值，类似《最后生还者》的越肩视角。带树干防穿模和受击/爆炸震屏。
- **Character**：自由移动时人物朝移动方向；瞄准时人物朝镜头方向并可横移，持杖手臂随俯仰角抬起，躯干扭转成“持枪”姿态。
- **Control**：火球从杖头宝石发出，飞向屏幕中心射线命中的点（敌人/树/地面），保证“指哪打哪”。

## 第一人称（V）
- 参考《地牢之子》法师视角：画面右下为持骨玉权杖的右手，左下为施法的左手；蓄力时左手抬到画面中下方，掌心魔法团逐渐变大后前推掷出。
- 视野 76°，瞄准（右键/Q）收窄到 58°；有走路晃动、鼠标惯性摆动、施法后坐与闪身倾斜。手臂单独渲染，不会穿进树木或敌人。
- 法杖杖头有火 / 冰 / 玉 3 个小魔法球环绕（第一、第三人称都有），蓄力时转速加快、向杖头收拢。

## 战斗
- 蓄力：每发 0.6 秒（首发与连发相同）。左手凝聚一团噪声扰动、不规则翻涌的魔法能量，能量丝螺旋汇入并逐渐变大，满蓄后掷出；准星外圈有蓄力环。蓄力时移动变慢、不能奔跑。
- 冰球术：伤害为火球的 80%，命中及溅射目标减速 50%（3 秒）。
- 鼠标：开始游戏时接管鼠标（Pointer Lock）并隐藏光标；若当前环境不允许锁定，会隐藏光标并启用“光标靠近屏幕边缘自动转向”。
- 火球：直击 30–40 伤害（15% 暴击 ×1.8），2.6m 溅射，附带 2 秒燃烧；击退并打断半兽人蓄力。
- 敌人：半兽人、半兽战士（会巡逻、发现后追击、蓄力挥斧），每击杀 12/27/42… 个出现首领「半兽勇士」。
- 场景：程序化生成的森林、发光蘑菇、沃玛寺庙废墟，全部为原创几何体，无外部素材。
