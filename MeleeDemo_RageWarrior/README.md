# 沃玛森林 · 怒气战士（近战战斗演示）

- 运行：双击 `index.html`（联网从 CDN 加载 three.js），或双击 `start.command`（使用本文件夹 lib/ 里的 three.js，离线可用）。
- 设计说明见 `DESIGN.md`。

| 按键 | 作用 |
|---|---|
| WASD | 移动（可以边走边打） |
| 鼠标 | 转镜头 |
| 左键 / Tab | 选中准星下的敌人 / 切换目标 |
| （自动） | 靠近目标自动普攻，积累怒气 → 怒气点（最多 3） |
| Q / 1 | 裂斩：1 点，50% 触发【破绽】或【狂怒】 |
| E / 2 | 斩首：1 点，破绽 ×3 必暴击，目标 <25% ×2 |
| R / 3 | 旋风斩：仅狂怒时，免费 AOE，每命中 +15 怒气 |
| 空格 / F | 护盾：2 点，30 秒，吸收最大生命一半的伤害，打空提前消失 |
| Esc | 暂停 |
